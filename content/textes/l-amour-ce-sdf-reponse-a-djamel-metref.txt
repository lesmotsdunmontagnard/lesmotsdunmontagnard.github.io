L'amour ce SDF(réponse à Djamel Metref)

Il est partout il suffit de le deviner .

Dans les silence des regards .
Dans les frissons des mots tus.
Dans le souffle suspendu.

Entre deux cœurs brûlants.
Entre deux corps entrelacés.
Dans les abysses d'un regard.

Dans les recoins d'un nid douillet.
Dans la mémoire des âmes égarées.
Dans la musique intérieure.

Entre deux décibels complices.
Dans les petits gestes routiniers.
Dans les replis d'un cœur discret.

Dans la chaleur d'une absence.
Dans le bonheur d'une présence.
Dans l'élan des bras qui s'ouvrent et s'élancent.

Dans le creux du monde.
Dans le gouffre du désespoir.
Entre les heures .
Entre les lignes.

L'amour est là, fragile et vaste.
Dans ce qui reste.
Dans les miettes.
Dans les airs...

Il suffit de l'invoquer.
De croire en lui.
De le laisser nous prendre.
Nous surprendre.

Publication Facebook le 29 mars 2026
